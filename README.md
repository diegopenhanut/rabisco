# Sala de Rabiscos da Mestra Ludmila

Jogo de desenho: sorteia um tema, todo mundo desenha ao mesmo tempo (1–3 min) e vota no melhor.

- **Online:** os celulares se conectam direto entre si (WebRTC via [Trystero](https://github.com/dmotz/trystero), descoberta pela rede Nostr). Sem servidor, sem conta.
- **Sem internet:** quem usar o mesmo código e o mesmo tempo recebe o mesmo tema; as rodadas são alinhadas pelo relógio do celular.

Publicar: suba estes arquivos num repositório e ative GitHub Pages (Settings → Pages → branch `main`, pasta raiz).
Convite: `https://SEU-USUARIO.github.io/rabisco/#codigodasala`
